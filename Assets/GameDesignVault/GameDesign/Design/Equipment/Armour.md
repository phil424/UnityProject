# Armour
### Known Goal
Armour should contribute to preparation/buildcraft rather than just be larger defence numbers.

### Explore
- defensive identity
- ability grants
- augment sockets
- status resistance
- unique mechanics
- armour families
- set effects
- single-piece versus multi-piece equipment.

# Persistent Armour Progression Tree

Each armour set may have its own authored permanent progression tree.

Potential node types include:

### Incremental
- +Armour;
- +Maximum Health;
- +Movement Speed;
- +status resistance;
- improved recovery / sustain.

### Unlock
- additional augment slot;
- additional ability / utility slot;
- defensive ability;
- movement mechanic;
- passive effect;
- resistance mechanic.

### Identity
- retaliation behaviour;
- shield generation;
- low-health bonuses;
- dodge / avoidance interaction;
- knockback resistance;
- healing interaction;
- unique set mechanic.

Different armour sets should develop different identities rather than eventually
converging on the same collection of statistical upgrades.
