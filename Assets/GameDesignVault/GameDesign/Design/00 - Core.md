# Core Game Design

# Game Vision

A run-based autobattling hunting game where the player prepares a hero,
enters a dynamically evolving region, influences autonomous combat through
carefully timed abilities, develops a temporary build, hunts monsters for
persistent rewards, and survives escalating threats for as long as possible.

# Core Design Pillars

## Autonomous Combat, Deliberate Intervention

The character handles routine combat execution.
The player watches the battle and decides when to intervene with active abilities.

## Buildcraft Is the Heart of the Run

Runs should become memorable because of the interactions and build that emerged.

## Preparation Creates Direction; the Run Creates the Build

The player can influence their starting strategy but cannot completely guarantee
their finished build.

## Permanent Progression Expands Possibility

Permanent progression primarily unlocks new options, combinations and starting
strategies rather than endless raw-stat growth.

## Randomness Respects Intent

Reward systems should understand the player's existing build and provide
meaningful choices rather than arbitrary dead options.

## Danger Creates Opportunity

Dangerous world states such as upsurges, boss overlaps and environmental events
should frequently be desirable opportunities as well as threats.

## Failure Ends the Run, Not Ownership

Death ends temporary run progression.
Persistent resources and rewards already earned remain owned.

## Escalation Toward Absurdity

Expeditions continually escalate through increasingly dangerous combinations,
culminating in an Apex before potentially continuing into endless post-Apex survival.

# Game Is Not
- An extraction looter.
- A traditional direct-control action RPG.
- A passive idle game.
- A pure RNG build generator.
- A game primarily about permanent numerical power creep.

# Current Major Unknowns
- Final active ability capacity and slot structure.
- Ability resource/economy model.
- Permanent versus temporary augment boundaries.
- Final traversal behaviour.
- Armour identity.
- Extent of meta progression.
- Supporting character model.
