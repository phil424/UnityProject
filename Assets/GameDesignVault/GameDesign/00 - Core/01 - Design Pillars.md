This should contain the principles we've already uncovered.

### Autonomous Combat, Deliberate Intervention

Basic combat execution is handled automatically.

The player influences outcomes through judgement and timed abilities.

### Buildcraft Is the Heart of a Run

Individual runs should become memorable because of the build that emerged.

### Preparation Creates Direction, the Run Creates the Build

The player can deliberately establish part of a strategy but cannot construct the entire finished build before entering.

### Permanent Progression Expands Possibility

Unlocking more content should primarily give the player additional choices, combinations and starting strategies.

### Randomness Should Respect Intent

A player starting a Bleed-oriented run should receive relevant opportunities rather than being presented with completely unrelated choices.

### Danger Creates Opportunity

Dangerous ecological events should often be attractive because of the rewards available.

### Failure Ends the Build, Not Ownership

Death ends temporary run progression.

Previously earned persistent resources remain earned.

### Runs Escalate Toward Absurdity

The game progressively combines more dangerous situations until the build can no longer survive.

### Several Good Answers Are Better Than One Correct Answer

World state, rewards and buildcraft should encourage adaptation rather than reveal one universally optimal strategy.
