## Moment-to-moment

```
Observe Combat
    ↓
Read Threat
    ↓
Watch Weapon Combo
    ↓
Activate / Hold Ability
    ↓
Observe Outcome
```

## Encounter loop

```
Read Current World / Forecast
 ↓
Choose Encounter
 OR
Allow Ambient Autopilot
 ↓
Travel Through Region
 ↓
Ambient Combat / Encounter Approach
 ↓
Commit to Encounter
 ↓
Auto Combat + Player Abilities
 ↓
Earn Resources / Pending Rewards
 ↓
Redirect / Continue
```

## Expedition loop
```
Prepare Persistent Build
 ↓
Start New Expedition
 ↓
Fresh World Time / Temporary Build
 ↓
Encounter Supply Begins
 ↓
Choose / Hunt / Travel
 ↓
Gain Temporary Build Power
 ↓
Escalation Rises
 ↓
Intensity Peaks and Falls
 ↓
World Events / Rare Opportunities / Bosses
 ↓
Apex
 ↓
Expedition Success
 ↓
Return
 OR
Continue Into Post-Apex Endurance
 ↓
Eventually End / Die
```

## Long-term loop
```
Prepare Character / Equipment
 ↓
Start Expedition
 ↓
Earn Temporary Power
 +
Earn Persistent Progress
 ↓
Succeed / Fail / End Expedition
 ↓
Temporary Build Resets
 ↓
Persistent Rewards Remain
 ↓
Craft / Upgrade / Unlock
 ↓
Create Stronger / Different Starting Configuration
 ↓
New Expedition
```
