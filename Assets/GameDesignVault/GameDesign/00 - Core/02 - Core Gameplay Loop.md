## Moment-to-moment

```
Observe Combat
    ↓
Read Threat
    ↓
Watch Weapon Combo
    ↓
Activate / Hold Ability
    ↓
Observe Outcome
```

## Encounter loop

```
Travel
 ↓
Encounter
 ↓
Auto Combat + Player Abilities
 ↓
Earn Resources / Pending Rewards
 ↓
Choose Next Destination
```

## Expedition loop

```
Prepare Build
 ↓
Enter Region
 ↓
Hunt
 ↓
Gain Temporary Build
 ↓
Threat Escalates
 ↓
Apex
 ↓
Post-Apex Survival
 ↓
Death
```

## Long-term loop

```
Complete Expedition
 ↓
Keep Materials / Unlocks
 ↓
Craft / Unlock / Experiment
 ↓
Create New Starting Configuration
 ↓
New Expedition
```
