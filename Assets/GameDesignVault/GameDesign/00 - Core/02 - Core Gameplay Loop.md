## Moment-to-moment

```
Observe Combat
    ↓
Read Threat
    ↓
Watch Weapon Combo
    ↓
Activate / Hold Ability
    ↓
Observe Outcome
```

## Encounter loop

```
Read Current World / Forecast
 ↓
Choose Encounter
 OR
Allow Ambient Autopilot
 ↓
Travel Through Region
 ↓
Ambient Combat / Encounter Approach
 ↓
Commit to Encounter
 ↓
Auto Combat + Player Abilities
 ↓
Earn Resources / Pending Rewards
 ↓
Redirect / Continue
```

## Expedition loop
```
Prepare Build
 ↓
Enter Region
 ↓
Encounter Supply Begins
 ↓
Choose / Hunt / Travel
 ↓
Gain Temporary Build Power
 ↓
Escalation Rises
 ↓
Intensity Peaks and Falls
 ↓
World Events / Rare Opportunities / Bosses
 ↓
Apex
 ↓
Post-Apex Endless Escalation
 ↓
Build Can No Longer Survive
```

## Long-term loop

```
Complete Expedition
 ↓
Keep Materials / Unlocks
 ↓
Craft / Unlock / Experiment
 ↓
Create New Starting Configuration
 ↓
New Expedition
```
