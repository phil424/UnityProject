### Purpose

Define the game in a way that someone can understand without reading the rest of the documentation.

### Put in it

#### Elevator Pitch

Something close to:

> A run-based autobattling hunting game where the player prepares a hero, enters a dynamically changing region, influences autonomous combat through carefully timed abilities, develops a temporary build, hunts increasingly dangerous monsters for permanent rewards, and survives escalating threats for as long as possible.

#### Genre

- Autobattler
- Roguelike / run-based
- Buildcraft
- Monster hunting
- Persistent collection

#### Player Fantasy

> Prepare a character I understand deeply, enter an unpredictable hunting region, adapt to what happens, assemble powerful interactions, hunt the targets I care about, and see how far the build can survive.

#### What the Game Is

- Combat is primarily autonomous.
- Player skill comes from judgement and ability timing.
- Runs contain temporary build progression.
- Long-term progression expands options.
- Regions change during runs.
- Bosses and world events create strategic choices.
- Buildcraft is a central source of replayability.

#### What the Game Is Not

- Not an extraction looter.
- Not a traditional direct-control action RPG.
- Not a passive idle game.
- Not pure RNG.
- Not permanent stat progression with endless vertical power creep.
- Not dependent upon procedural map generation.
